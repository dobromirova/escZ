EscZ is a website built for mountain lovers, where each user can share routes they've visited with their designated location and photography. It is a social website, in which you can find your next favorite climbing spot, according to your skill level, which you can filter out.

Code functionality: Built with Spring Boot, it has an MVC structure. It contains controllers, entities, services, views, repositories and validations. Implemented bootstrap page with Thymeleaf. Spring Security and i18n for English and Spanish. MySQL database and custom queries. User management and interaction through a comment system.
